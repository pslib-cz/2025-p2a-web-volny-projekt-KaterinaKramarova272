## O projektu

_Krátce popište svůj projekt – čemu se věnuje, co nabízí a jaký problém řeší?_

`Projekt se věnuje freestyle inline skatingu — sportu, který kombinuje technické triky, kreativitu a svobodu pohybu v městském prostředí. Web představuje tento sport nově příchozím, ukazuje jeho možnosti, různé styly jízdy a inspirativní ukázky. Zároveň nabízí zájemcům možnost připojit se ke freestyle skating klubu v Jablonci nad Nisou a aktivně se účastnit akcí a tréninků spojených s tímto sportem. Cílem webu je nejen informovat, ale také motivovat lidi k tomu, aby vzali brusle a přidali se k naší komunitě.`

## Cílová skupina

_Kdo je váš cílový uživatel / zákazník? Popište typického zástupce cílové skupiny._

`Zájemci o sport a konkrétně inline bruslení — lidé, kteří nechtějí jen jezdit dokola, ale chtějí se naučit triky, zlepšovat se a posouvat své hranice. Web je určen jak pro úplné začátečníky, kteří o freestyle skatingu teprve slyší a chtějí vědět víc, tak pro pokročilejší bruslaře, kteří hledají komunitu podobně smýšlejících lidí. Typický návštěvník je mladý člověk, který miluje pohyb, svobodu a městské prostředí, a hledá sport, který ho bude bavit a zároveň ho propojí s novými přáteli.`
